# Dellkix GNU/Linux

definitely not as useful, BUT works really well for learning about:
- CMake
- syscalls
- init
- filesystems
- kernel
- bootloader
- shell scripts


## very important!!

1. `build-rootfs.sh` must be run inside your kernel directory (aka the kernel you downloaded to build this)
2. this system is run using linux 6.18.55-lts, you can try other kernel versions, *but i don't know if this works!*
3. this is just a small, personal project, with no intention of actually being useful (although it's looking good for my first linux project), if you like what i'm doing tho, maybe give this repo a star :)
